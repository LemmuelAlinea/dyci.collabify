# Collabify DFD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Level 0 and Level 1 data flow diagrams of Collabify as PNG, SVG and draw.io, plus a thesis text guide.

**Architecture:** One dependency-free Node script (`docs/dfd/build-dfd.mjs`) holds each diagram as data (nodes with x/y/w/h, edges with label and waypoints) and writes one SVG per level and one two-page `.drawio`. Headless Chrome renders each SVG to PNG at 3x.

**Tech Stack:** Node (no packages), Chrome `--headless --screenshot`.

**Spec:** `docs/superpowers/specs/2026-11-19-dfd-design.md`

## Global Constraints

- Gane & Sarson: entity = square box, duplicate marked with a corner diagonal; process = rounded rectangle with a top number band; store = open-ended rectangle with an ID cell.
- Black on white, Arial, landscape. Labels are noun phrases.
- Entity, process, store names and numbers exactly as in the spec tables.
- No app code, schema or package changes.

## Review Focus

- Arrow labels overlapping boxes or each other: check every PNG by eye at full size.
- Level 0 / Level 1 balance: every Level 0 flow appears on Level 1 (the script asserts it).
- draw.io opens both pages with editable shapes and connected edges (open in app.diagrams.net).
- Text overflowing a box: names wrap inside their shape.
- Arrow direction: in/out matches the spec's Level 0 table.
