# Launch film v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 2:22 landing-page film (hook → welcome → make it yours → work spaces → educational side → close) that replaces `public/video/collabify-film.mp4`.

**Architecture:** A new HyperFrames project `cinema-v3/` cloned from the October `cinema/` architecture: one `index.html`, one paused GSAP timeline, scenes as `js/sNN.js` builders pushed to `window.SCENES`, product UI rebuilt in HTML from the real tokens. The only generated footage is a 9 s Higgsfield hook clip. Scene start times come from the voice-over wav durations, held in one file.

**Tech Stack:** HyperFrames 0.8.115 (Node 24), GSAP 3, Kokoro TTS (`npx hyperframes tts`, voice `af_heart`), Python for music/SFX/captions, Higgsfield MCP (free credits only), React landing page (`src/components/landing/Workflow.tsx`).

**Spec:** `docs/superpowers/specs/2026-11-24-launch-film-v3-design.md`

## Global Constraints

- Total length ≤ 150.0 s, target 142 s; 1920×1080, 60 fps.
- Higgsfield: free plan, 10 credits. Spend exactly one `gpt_image_2_6` still (0.75) and one `grok_video_v15_lite` 9 s 720p 16:9 clip (9). Never call `show_plans_and_credits`, never buy, never use a paid model. The still is shown to the owner before it is animated.
- Order: hook, Welcome, Make it yours, work spaces (7 beats), educational (5 beats), close.
- Hook copy, exact: "Chats in one app. Files in another. Deadlines in your head." then "What if your whole project lived in one place?"
- Run HyperFrames with Node 24: `export PATH="/c/Program Files/nodejs:$PATH"`.
- Write large JS/HTML with the Write tool, not heredocs. Never fade `.cam`; fade `.fade`.
- Colors only from the token set copied from `cinema/css/ui.css`; statuses use success/warning/danger/pending, never brand amber.
- Copy: sentence case, active voice, no exclamation marks, no "please", no "successfully". Product names as the app writes them: Tasks from notes, Break down and balance, Suggest sprints, Workflow rules, Waiting on you, Hand-in & grade, Rate your team.
- Demo data is invented (no real people, no real student names).
- `cinema/` and `cinema-portrait/` stay untouched. Commit locally; do not push main.

## Review Focus

- Long labels in rebuilt panels overflowing their boxes at 1080p → every scene's contact sheet is checked for clipped text (Tasks 3–7).
- Voice-over running past its scene, or the total creeping past 150 s after re-records → `tools/check-timing.mjs` fails the build (Task 2, re-run in Task 8).
- Captions drifting from the voice (VTT times from scene starts, not wav order) → captions are generated from `js/timings.js` (Task 7).
- The 720p hook clip looking soft at 1080p → it is graded and slightly vignetted/grained under the type, never shown full-bleed sharp-edged (Task 3).
- The landing chapter list pointing at old times → `CHAPTERS` is generated by hand from `js/timings.js` and checked by seeking each chapter in the browser (Task 9).
